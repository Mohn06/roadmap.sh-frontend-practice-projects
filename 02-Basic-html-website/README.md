# Basic-HTML-Website

## Goal

The goal of this project is to create a website using HTML only with different sections of a website like header, footer, navigation, main content, sidebars etc.

## Requirements

The website should have the following pages:

- Homepage
- Projects
- Articles
- Contact

## Submission Checklist

- [x] Semantically correct HTML structure.
- [x] Multiple pages with a navigation bar.
- [x] SEO meta tags in the head of each page.
- [x] The contact page should have a form with fields like name, email, message etc.
